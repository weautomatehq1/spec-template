# Decisions

> Index of Architecture Decision Records (ADRs).
> Individual ADRs live in `docs/decisions/`.
> Format follows MADR (Markdown Any Decision Record).

## How to add an ADR

1. Copy the MADR template from `weautomatehq1/factory/docs/decisions/_template.md`
2. Name it `docs/decisions/NNNN-short-title.md` (zero-padded, kebab-case)
3. Fill in all sections — especially **decision** and **consequences**
4. Update the index table below
